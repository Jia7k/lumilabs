# Lumi5 Option 4 Logo Refinement Design

## Goal

Refine the selected option 4 icon into a small set of polished logo-mark
mockups. The mark should communicate Lumi5 Labs connecting two parties while
remaining recognisable as `{;}`.

## Approved Direction

- Use the existing Lumi5 purple, `#6B4EE6`, as a single flat colour.
- Preserve two opposing brace forms as the connected parties.
- Keep a clear semicolon centred between the braces as the intermediary.
- Use smooth, symmetrical geometry with careful optical balance.
- Avoid gradients, shadows, lighting, depth, texture, text, and unrelated
  symbols.

## Variations

Generate four controlled variations of the same concept:

1. **Balanced** — moderate stroke weight and spacing; the primary recommendation.
2. **Compact** — heavier construction and tighter spacing for very small use.
3. **Rounded** — softer terminals for a more approachable personality.
4. **Sharp** — crisper terminals for a more technical personality.

Each variation must remain visibly related to option 4 rather than becoming a
new logo direction.

## Presentation and Success Criteria

- Present each variation as a centred purple mark on a clean white background.
- Use a square composition with generous, consistent padding.
- The braces must remain visually separate and balanced.
- The semicolon must read correctly and must not resemble a person, exclamation
  mark, or random punctuation.
- The silhouette must remain understandable when mentally reduced to the
  website's existing 30-pixel navbar icon size.
- These outputs are preview mockups only. No website asset or application code
  will be changed until the user selects and approves a final refinement.
